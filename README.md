# SECUREDESK-BREACHROOM
### Advanced Endpoint Security & Compliance Auditing Framework

SECUREDESK is a professional security auditing tool designed to check 95+ critical security controls on a corporate desktop/laptop and prevent data breaches.

This tool is built for IT Admins to ensure every employee system is compliant before allowing network access.

#### 🚀 Key Features
- **95 Real-Time Security Checks:** From Antivirus to USB blocking, Firewall, Password Policy, etc.
- **Modular Architecture:** Each check is an independent module in `securedesk/checks/`
- **Breach Prevention:** Detects misconfigurations that can lead to data leaks.
- **Compliance Ready:** Helps meet ISO 27001, SOC 2 requirements.
